Get started

Your first methane map.

Set up HyGAS, prepare an EnMAP scene, and retrieve methane enhancement with instrument-noise uncertainty.

This guide uses the published CH₄ retrieval workflow and the current develop branch. Processing runs on your computer. You will need Git, Mamba, and satellite inputs obtained separately.

Step 01

Install HyGAS

Clone the repository and select develop. The environment file supplies Python 3.11 and the geospatial dependencies; the requirements file adds the Python packages used by the project.

Terminal · repository and environment
git clone https://github.com/AlFe23/hygas.git
cd hygas
git checkout develop

mamba env create -f environment.min.yml
mamba activate hygas
python -m pip install -r requirements-pip.txt

Check that the active Python interpreter can load GDAL before preparing a retrieval.

Terminal · verify GDAL
python -c "from osgeo import gdal; print(gdal.VersionInfo())"

A GDAL version string confirms that the bindings are importable. Keep the hygas environment active for the following commands.

Reproducing the paper? The publication snapshot is preserved separately as mdpi-methane-paper-v1.0. Use that version and its recorded configuration when reproducing published results. This guide follows current development.

Step 02

Prepare an EnMAP scene

Start with a Level-1B product. Keep its VNIR, SWIR, and XML files together and match the acquisition, segment, and processing version. EnMAP obtains the required scene geometry and atmospheric information from its metadata; this route does not require a separate DEM.

  • VNIR radiance: the scene’s …-SPECTRAL_IMAGE_VNIR.TIF.
  • SWIR radiance: the matching …-SPECTRAL_IMAGE_SWIR.TIF.
  • Metadata: the matching …-METADATA.XML.
  • Methane LUT: dataset_ch4_full.hdf5, obtained from the University of Utah HIVE dataset. Retain the dataset’s citation and attribution.
  • EnMAP SNR reference: the NPZ already included in the repository, shown below.
Included reference · relative to the repository root
reference_snr/enmap/L1B-DT0000001584_20220712T104302Z_001_V010502_20251017T093724Z/snr_reference_columnwise.npz

Satellite radiances and LUTs are separate downloads; cloning HyGAS supplies the code and selected SNR references. See the reference-SNR guide for their scope and limitations.

Step 03

Run a single-scene retrieval

Run this command from the repository root. Replace every /path/to/… input with your local file path. The output directory will receive the results.

Terminal · EnMAP CH₄, column-wise matched filter
python scripts/main.py \
  --satellite enmap --mode scene --gas ch4 \
  --vnir /path/to/scene/ENMAP-SPECTRAL_IMAGE_VNIR.TIF \
  --swir /path/to/scene/ENMAP-SPECTRAL_IMAGE_SWIR.TIF \
  --metadata /path/to/scene/ENMAP-METADATA.XML \
  --lut /path/to/dataset_ch4_full.hdf5 \
  --snr-reference reference_snr/enmap/L1B-DT0000001584_20220712T104302Z_001_V010502_20251017T093724Z/snr_reference_columnwise.npz \
  --output outputs/enmap-first-scene \
  --min-wavelength 2100 --max-wavelength 2450 \
  --enmap-mf-mode full-column

full-column selects the column-wise clutter-matched filter (CWCMF), the primary reference configuration in the published multi-sensor cases. The command explicitly records the 2100–2450 nm methane window.

Use separate output directories when comparing methods. The user guide maps the paper’s method names to the CLI options.

Step 04

Read your results

Open the GeoTIFFs in a GIS application and inspect the processing report. The filename prefix comes from the input product.

Expected EnMAP files for this configuration
FileWhat it contains
*_MF.tifMethane enhancement ΔX, in ppm·m.
*_MF_uncertainty.tifPropagated instrument-noise uncertainty σRMN, in ppm·m.
*_RGB.tifAn RGB scene quicklook for spatial context.
*_CL.tifThe technical classification map used by the selected method. In full-column, labels identify detector columns.
*_CH4_target.npyThe generated methane target spectra.
processing_report.txtInput paths, processing parameters, spectral window, and output paths.

Enhancement is not emission rate. ΔX measures excess methane along the optical path. The uncertainty raster describes the instrument contribution. To estimate plume mass and flux, continue with reviewed segmentation, background-clutter estimation, and a wind input with its uncertainty.

The uncertainty guide explains how σRMN, background variability, IME, and wind enter that analysis.
