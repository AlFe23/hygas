Your local workspace

The code runs with your data.

Start with the curated Python environment. The quick start walks through the EnMAP inputs, a complete command, and the files to inspect afterwards.

Satellite products and the gas LUT are obtained separately. Selected reference-SNR files are included in the repository.

Set up HyGAS step by step →
Terminal / initial setup
git clone https://github.com/AlFe23/hygas.git
cd hygas
git checkout develop

mamba env create -f environment.min.yml
mamba activate hygas
python -m pip install -r requirements-pip.txt

Current development setup. For the reviewed paper results, use the publication snapshot.
